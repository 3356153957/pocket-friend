# Pocket Friend Cloudflare 脱敏部署设计

## 目标

将 Pocket Friend 的公开演示版部署到 Cloudflare，发布产物中不包含 `.env`、API Token、密码、私钥或 Cloudflare Secrets。先使用 Cloudflare 提供的默认域名完成上线和验证，之后再绑定自定义域名。

旧 GPT Sites 地址当前返回 404，Sites 管理接口也找不到对应项目；迁移完成后仍会复核该地址保持不可访问，并移除仓库中的旧 Sites 绑定文件。

## 功能边界

公开版保留纯前端可运行的问卷、PALS、导航与本地演示数据。

以下能力依赖外部服务或服务端凭据，公开版中必须显式停用，不允许静默向同源路径或历史服务器发请求：

- 高德真实地图与定位服务
- AI/豆包照片生成
- 产品、头像和照片 API
- 管理后台、在线状态与设备心跳
- Supabase、JACOO 及其他远程数据服务

停用功能应显示清晰的“演示版未启用”状态，不展示变量名、服务器地址或内部错误。

## 架构

浏览器只加载 Vite 生成的静态 HTML、CSS、JavaScript 和本地资源。Cloudflare Pages 负责静态托管与 SPA 路由回退，不部署 Functions、Workers 业务逻辑、数据库或对象存储。

构建引入专用的公开演示模式。该模式从代码层阻断远程初始化和接口请求，而不依赖“环境变量恰好为空”。生产构建命令使用空白、隔离的环境上下文，并输出到独立目录供扫描和发布。

## 脱敏与安全门禁

发布前必须完成以下检查：

1. Git 跟踪文件检查：禁止提交 `.env`、密钥文件、Cloudflare 凭据和构建缓存。
2. 构建模式测试：确认公开演示模式不会启动 presence、地图 SDK、照片或产品 API。
3. 产物扫描：检查敏感变量名、Bearer/API Key 模式、已知服务器地址、私钥头和高熵可疑值。
4. 网络验证：浏览器冒烟测试确认页面不会请求业务 API 或第三方地图/AI 域名。
5. HTTP 验证：默认域名返回成功状态，SPA 深链接可回退，安全响应头生效。

扫描脚本不得读取或打印本地 `.env` 的值；只检查受控的构建目录和 Git 跟踪文件。

## Cloudflare 发布

采用 Cloudflare Pages Direct Upload：本地完成可复现构建和扫描后，仅上传独立静态输出目录。Wrangler 的登录凭据保留在本机用户配置中，不写入仓库，也不进入发布目录。

若本机尚未登录 Cloudflare，使用浏览器 OAuth 登录，不要求用户在对话中粘贴 API Token。

## 切换、域名与回滚

切换顺序固定为：构建与扫描通过 → 上传 Cloudflare → 验证默认域名 → 复核旧 GPT Sites 地址不可访问 → 移除旧 Sites 本地绑定。

自定义子域名可在 Pages 项目中添加后，通过 CNAME 指向 `<project>.pages.dev`；根域名需交由 Cloudflare DNS 管理。域名绑定不阻塞默认域名上线。

若 Cloudflare 验证失败，不修改 DNS，也不删除可恢复的本地配置；修复后重新上传。旧 GPT Sites 当前已是 404，因此不存在需要回切的公开站点。

## 验收标准

- Cloudflare 默认域名可访问，核心纯前端流程可操作。
- 发布目录及线上脚本中没有敏感凭据、私有服务器地址或业务 Token。
- 浏览器没有业务 API、地图、AI、后台或设备心跳请求。
- 旧 GPT Sites 地址继续返回 404。
- 仓库保留可重复执行的构建、扫描、测试与部署说明。
